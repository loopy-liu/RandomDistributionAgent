# 随机分布仿真 Agent 核心骨架（V0.4.1 本地验收修订版）

这是拔高部分的第一阶段技术原型，不是最终完整系统。

## 当前已实现
- 统一分布插件接口：`validate_parameters()` 与 `sample()`
- 分布注册中心：按唯一 ID 注册和查找分布
- 仿真服务：统一校验样本数量、创建局部随机数生成器、调用插件
- 枚举分布插件：复用基础作业中的累积概率区间映射思路
- XML 导出：统一 `simulation` 根结构，支持标量和嵌套向量样本
- 单元测试：参数校验、样本数量、随机种子复现、频率近似、XML 解析

## 尚未实现

- 其余 26 种分布
- 自定义分布图形化创建
- 数据库、成员登录与权限
- 云端部署

## 统一接口约定
所有分布插件都需要提供：
- `metadata`：分布元数据
- `validate_parameters(params)`：验证并规范化参数
- `sample(n, params, rng)`：生成 n 个样本

仿真服务只依赖这个接口，不需要知道分布内部如何采样。

## 关于 XML 格式
当前 XML 是本项目拟定的统一格式示例。老师原始要求没有给出 XML 样例或 XSD，因此正式提交前仍需与老师提供的格式要求核对。


## V0.2 新增：自定义连续型分布（PDF）
- 用户可提交分布名称、数学表达式、有限区间和数值积分网格精度。
- 表达式通过 AST 白名单解释，不使用 `eval()` 或 `exec()`。
- 当前支持变量 `x`、常量 `pi/e`、四则运算、乘方及常见数学函数。
- 在有限区间上进行数值积分，构造近似 CDF，再通过逆 CDF 数值采样。
- 自定义分布定义保存在 SQLite；支持新增、查询、修改、删除。
- 程序启动时可从数据库重新加载自定义分布，无需为每条自定义分布编写新 Python 类。

### 自定义 PDF 示例
- 名称：递增密度示例
- 表达式：`2*x`
- 区间：`[0, 1]`
- 该函数在区间上的积分为 1；理论均值为 2/3，可用大量样本的均值作近似验证。

### 当前边界
- 当前自定义函数功能面向一维、有限区间、非负且可积的连续概率密度函数。
- 不支持任意 Python 代码、无限区间、奇异点自动处理或多维自定义密度。
- 数值积分与逆 CDF 为网格近似，正式使用前需根据目标精度选择网格大小。
- 自定义离散 PMF、前端图形界面、数据库成员权限和云端部署仍需继续开发。

## V0.4 新增：27 种内置分布注册与动态参数界面
- 根据老师清单（排除第 5 项 constant real distribution）注册 27 种内置分布。
- 新增 26 种分布插件，原枚举分布插件保留。
- 图形界面改为读取插件 metadata 自动生成参数输入控件。
- 支持多元正态分布的向量与协方差矩阵 JSON 输入。
- 多元样本在结果表中按维度展开，并展示前两个维度的联合散点图。
- 对二项、超几何、Pascal、Poisson 和 KS 采样增加基本计算量保护。
- 所有内置分布均使用相同的 `validate_parameters()` / `sample()` 接口。

## V0.4 参数约定提示
- 几何分布：按 Apache Commons Math 定义，输出首次成功前的失败次数，支持集从 0 开始。
- Pascal 分布：输出达到 r 次成功前的失败总次数。
- Zipf 分布：有限支持集 1,...,N，概率正比于 1/k^s。
- Kolmogorov–Smirnov：通过模拟 n 个 U(0,1) 样本并计算双侧单样本统计量 D_n 生成分布样本。
- 多元正态：输入均值向量与协方差矩阵；当前实现要求协方差矩阵对称正定。
- Lévy：采用位置参数 μ、尺度参数 c 的 Lévy 参数化。

## V0.4 已知限制
- 二项、超几何和 Pascal 使用直接循环抽样；大参数与大样本组合会触发工作量保护。
- Poisson 使用精确的分块 Knuth 算法，极大均值与大样本组合也会触发工作量保护。
- KS 分布采用 Monte Carlo 方式生成统计量样本，不是直接调用 Apache 的 CDF 计算算法。
- 多元正态暂不支持奇异半正定协方差矩阵。
- 自定义分布目前仍仅支持一维有限区间连续 PDF；自定义离散 PMF 需下一阶段实现。

## V0.5：双通道扩展机制（当前升级版）

### 1. 自定义离散型 PMF
- 在自定义分布管理中新增离散型 PMF。
- 用户填写数学权重表达式和有限整数支持集。
- 系统在支持集上检查非负、有限和非零总权重，并自动归一化。
- 使用累积概率映射生成离散样本。
- 支持 SQLite 持久化，以及新增、查询、修改、删除。
- XML 仿真结果会记录表达式、支持集和归一化方式，便于追溯。

示例：
- 泊松型权重：`exp(-4)*4**x/factorial(x)`，支持集 `0` 到 `15`。
- 二项型权重：`comb(10,x)*0.3**x*0.7**(10-x)`，支持集 `0` 到 `10`。

表达式解释器新增有界 `factorial(x)` 与 `comb(n,k)`，仍采用 AST 白名单，不使用 `eval()` 或 `exec()`。

### 2. 外部 Python 插件自动发现
- 项目根目录新增 `extensions/`。
- 启动时自动发现文件名匹配 `plugin_*.py` 的插件。
- 每个插件文件必须提供 `build_plugin()` 工厂函数。
- 返回对象必须实现 `metadata`、`validate_parameters(params)` 和 `sample(n, params, rng)`。
- 插件 ID 与已注册分布重复时会拒绝注册，并在系统说明页显示加载错误。
- 示例插件位于 `examples/plugin_bernoulli.py`；复制到 `extensions/` 并重启，即可验证自动发现。

**安全边界：** Python 文件导入时会执行代码，因此 `extensions/` 只能由可信开发者或管理员维护。不要将公网用户上传的 Python 文件放入该目录。普通成员的网页自定义功能应使用安全数学表达式（PDF/PMF），不能执行任意 Python 代码。
